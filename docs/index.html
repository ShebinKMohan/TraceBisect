TraceBisect Studio

Visual regression reports for AI-agent runs

TraceBisect compares baseline and candidate agent traces, highlights the first behavioral divergence, and turns the regression into a pytest test. The CLI is the engine; Studio is the SaaS-style dashboard around it.

$ tracebisect demo

V1 scope

  • OpenTelemetry/OpenInference JSON and native .tbtrace ingestion.
  • Parent-local trace alignment with stable-ID, structural, and positional tiers.
  • Five V1 divergence types with deterministic severity classification.
  • Terminal diff rendering plus generated pytest tests using tracebisect.testing.
  • FastAPI + React Studio dashboard for visual comparison reports.

V1 Studio is intentionally narrow: no auth, billing, team RBAC, or hosted trace storage yet.
