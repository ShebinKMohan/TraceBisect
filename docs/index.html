TraceBisect

Git bisect for AI agent traces

A local-first CLI that compares two agent runs, finds the first meaningful behavioral divergence, and exports a pytest regression test that keeps the failure from returning.

Try the built-in demo

$ tracebisect demo
TraceBisect V1 demo

✗ First divergence at event 2: tool_call.search_database
  Severity: CRITICAL
  Type:     changed_tool_args

Debug a recorded failure

tracebisect ingest raw-otel.json baseline.tbtrace
tracebisect diff baseline.tbtrace candidate.tbtrace

Prevent it in CI

tracebisect export-pytest baseline.tbtrace \
  tests/test_refund_regression.py \
  --scenario "python examples/refund_agent.py --case refund_042" \
  --assert tool_args,final_output,cost

V1 scope

  • OpenTelemetry/OpenInference JSON and native .tbtrace ingestion.
  • Parent-local trace alignment with stable-ID, structural, and positional tiers.
  • Five V1 divergence types with deterministic severity classification.
  • Terminal diff rendering plus generated pytest tests using tracebisect.testing.

V1 intentionally does not include a dashboard, hosted SaaS, vendor-native importers, or git-history bisection.
